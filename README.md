# 📊 Company Sales Data Analysis & Interactive Dashboard

An end-to-end data analysis and visualization project built using **Google Sheets**. This project transforms raw e-commerce sales data into an interactive, monochrome-themed executive dashboard to track key business metrics, regional profitability, and customer behavior.

## 📌 Executive Summary

The objective of this analysis is to evaluate total revenue, order metrics, and profitability across different product categories and regions (focused on Poland). The resulting dashboard provides decision-makers with actionable insights through interactive filters and clean visual hierarchies.

---

## 🔑 Key Performance Indicators (KPIs)

* **Total Sales:** €1,924,338
* **Total Profit:** €224,078
* **Total Orders:** 1,365
* **Returned Orders:** 11 (**0.81%** Return Rate)

---

## 📈 Key Insights & Features

1. **Regional Performance (City Profits & Heatmap):**
   * Sales and order volumes are tracked across major Polish cities (*Warsaw, Krakow, Lodz, Wroclaw*).
   * Includes a weekly **City Order Heatmap** to identify high-density order days.

2. **Product & Category Analysis:**
   * **Top 5 Categories:** Ranked by total order volume to identify primary revenue drivers (*Paper, Binders, etc.*).
   * **Product Profitability Breakdown:** Detailed bar analysis highlighting high-margin items vs. underperforming categories.

3. **Customer Segmentation:**
   * Breakdowns across **Consumer**, **Corporate**, **Home Office**, and **Small Business** segments across main product divisions (*Furniture, Office Supplies, Technology*).

4. **Timeline & Return Tracking:**
   * Historical **Sales/Profit Timeline** to spot seasonal trends and revenue fluctuations.
   * Dedicated tracking for order return rates to ensure quality control.

---

## 🛠️ Tools & Methods Used

* **Google Sheets:** Data cleaning, transformation, and dashboard layout design.
* **Pivot Tables & Calculated Fields:** Aggregate metrics, custom grouping, and heatmaps.
* **Slicers & Dynamic Filtering:** Interactive filtering by *City*, *Product Sub-Category*, and *Customer Segment*.
* **Data Visualization:** Custom color palette (monochrome green), custom layout alignment, and KPI cards.
